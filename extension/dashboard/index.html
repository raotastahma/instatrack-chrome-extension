Delete this sync?

Reports and trend will be recalculated from the remaining syncs. Deleting the only sync clears this account's analytics. Other accounts stay stored. This action cannot be undone.

Destructive action

Reset all local data?

This stops any active sync and permanently removes the history, reports, and latest sync diagnostics for every Instagram account stored by this extension in this browser.

Downloaded CSV and JSON files stay on your device. Your usage analytics preference is kept; change it in the dashboard footer. This action cannot be undone.
